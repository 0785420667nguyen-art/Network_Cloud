\section*{\fontsize{16pt}{15pt}\selectfont ENTERPRISE NETWORK MANAGEMENT \\ON CLOUD PLATFORM USING SDN \\ABSTRACT}

Nowadays, many enterprises operate with a model consisting of a main office and multiple branches distributed across different locations. Managing, configuring, and monitoring network systems in the traditional way faces many challenges: manual configuration of each device, lack of centralized management, and difficulties in monitoring and troubleshooting. The development of Cloud Computing and Software Defined Networking (SDN) has opened up a new approach, enabling flexible, automated, and centralized network infrastructure management.

This thesis \textbf{"Enterprise Network Management on Cloud Platform using SDN"} researches and develops a modern enterprise network management model, combining Private Cloud with SDN technology. The system enables centralized management of all network devices through SDN Controller (Ryu Framework), automates VLAN and Flow Rule configuration, connects branches via VPN/GRE Tunnel, and provides a Web interface for real-time monitoring and management.

\textbf{Main content:}
\begin{itemize}
    \item \textbf{Chapter 1 -- Overview:} Presents the reasons for choosing the topic, research objectives, research scope, research methodology, and practical significance.
    
    \item \textbf{Chapter 2 -- Theoretical Background:} Introduces fundamental knowledge of Cloud Computing (IaaS, PaaS, SaaS, deployment models), Software Defined Networking (3-layer architecture, OpenFlow, SDN Controller), VLAN (Access Port, Trunk Port, IEEE 802.1Q, Inter-VLAN Routing), VPN/GRE Tunnel.
    
    \item \textbf{Chapter 3 -- System Analysis and Design:} Analyzes functional and non-functional requirements, designs enterprise network model, VLAN design and IP addressing, Private Cloud design, SDN Controller and REST API design, database design, Website management interface design.
    
    \item \textbf{Chapter 4 -- Implementation and Evaluation:} Presents deployment environment (hardware, software), Private Cloud deployment (Proxmox/OpenStack), SDN deployment (Ryu Controller, Open vSwitch), VPN/GRE Tunnel deployment, Website development (Backend API, Frontend Dashboard, Database), automation (VLAN generation, Flow Rule generation, routing, config push), performs test scenarios and evaluates performance (deployment time, throughput, latency, packet loss, system resources, scalability).
    
    \item \textbf{Chapter 5 -- Conclusion and Future Work:} Summarizes achieved results, analyzes limitations, proposes development directions (Kubernetes integration, Ansible, Multi-Controller, Prometheus/Grafana, Machine Learning, Zero-Touch Provisioning, Hybrid/Multi-Cloud, Security Enhancement, Intent-Based Networking).
\end{itemize}

\textbf{Achieved results:} The system significantly reduces device configuration time, simplifies network administration, enhances scalability when adding new branches or users, and provides real-time monitoring capabilities through an intuitive Web interface.

\textbf{Keywords:} Cloud Computing, Software Defined Networking (SDN), Ryu Controller, Open vSwitch, OpenFlow, VLAN, VPN/GRE Tunnel, Private Cloud, Enterprise Network Management.
